Couleurs sémantiques Les couleurs sémantiques permettent de transmettre le contexte du message affiché dans le toast, comme le succès, l'erreur, l'avertissement ou l'information.
Pour les utiliser, vous pouvez définir la propriété color du toast avec l'une des valeurs @for (color of semanticColors; track $index) { } Couleurs primaires Les couleurs primaires peuvent également être utilisées pour les toasts afin de s'adapter à l'identité visuelle de votre application. Pour les utiliser, vous pouvez définir la propriété color du toast avec l'une des valeurs @for (color of primaryColors; track $index) { }
